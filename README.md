# K.L Logistics | Premium Supply Chain

A high-end, multi-page logistics website featuring a custom Three.js cinematic scroll-jacking experience. As the user scrolls, a 3D truck drives down a digital highway and transforms into a global data network.

## 🚀 Features
- **Cinematic Scroll Animation**: Built with Three.js. The camera tracks a 3D truck that dissolves into a global particle sphere upon scrolling.
- **Premium UI**: Glassmorphism navigation, dark-mode first, neon teal accents.
- **Responsive Layout**: CSS Grid & Flexbox.

## 💻 How to Run
Open `index.html` in a modern browser. No build tools required.
